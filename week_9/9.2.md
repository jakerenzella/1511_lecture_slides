### Spotify Recap
---
### Freeing Memory: `delete_spotify`

So far, we've removed single nodes. But what about when the program ends? We need to free *everything* to prevent memory leaks.

This is the job of `delete_spotify`. It must systematically deallocate every `song`, every `playlist`, and the main `spotify` struct we created with `malloc`.

This is often called a "deep free" because we are freeing nested structures.

---
### The Strategy: Deconstruct from the Bottom-Up

We cannot simply `free(spotify)`. That would leave all the playlists and songs allocated on the heap with no way to reach them—a huge memory leak.

The only safe way is to deconstruct in the reverse order of construction:
1.  For a given playlist, free all its `song` nodes.
2.  Once the songs are gone, free the `playlist` node itself.
3.  Repeat this for every playlist in Spotify.
4.  Once all playlists are gone, free the main `spotify` struct.
---
	Inner loop for songs
```c
while (current_song != NULL) {
    // 1. Store a pointer to the next song. If we don't,
    //    freeing current_song makes current_song->next invalid.
    next_song = current_song->next;

    // 2. Free the current node.
    free(current_song);

    // 3. Move to the next node using our saved pointer.
    current_song = next_song;
}
```

---

	Outer loop for playlists
```c
while (current_playlist != NULL) {
    // The inner loop runs here, freeing all songs...

    // 1. Once the songs are gone, we save the next playlist.
    next_playlist = current_playlist->next;

    // 2. Free the now-empty current playlist.
    free(current_playlist);

    // 3. Move to the next playlist to continue the process.
    current_playlist = next_playlist;
}
```

---
### Implementation: Nested Loops
	The "bottom-up" strategy translates directly into nested loops. An outer loop iterates through the playlists, and an inner loop iterates through the songs of each playlist.
```c
void delete_spotify(struct spotify *spotify) {
    struct playlist *current_playlist = spotify->playlists;
    struct playlist *next_playlist;

    // Outer loop for playlists
    while (current_playlist != NULL) {
        struct song *current_song = current_playlist->songs;
        struct song *next_song;

        // Inner loop for songs
        while (current_song != NULL) {
            next_song = current_song->next;
            free(current_song);
            current_song = next_song;
        }

        next_playlist = current_playlist->next;
        free(current_playlist);
        current_playlist = next_playlist;
    }
    free(spotify);
}
```

// DO NOT CHANGE THIS FUNCTION
// create linked list from array of strings
struct node *strings_to_list(int len, char *strings[]) {
    struct node *head = NULL;
    for (int i = len - 1; i >= 0; i = i - 1) {
        struct node *n = malloc(sizeof (struct node));
        assert(n != NULL);
        n->next = head;
        n->data = atoi(strings[i]);
        head = n;
    }
    return head;
}

// print linked list
void print_list(struct node *head) {
    printf("[");

    for (struct node *n = head; n != NULL; n = n->next) {
        // If you're getting an error here,
        // you have returned an invalid list
        printf("%d", n->data);
        if (n->next != NULL) {
            printf(", ");
        }
    }
    printf("]\n");
}
